# AgroMind — Умный помощник садовода

React Native приложение для управления садом с AI-советами.

## Phase 1 MVP ✅

- ✅ Google OAuth авторизация
- ✅ CRUD операции с садами
- ✅ CRUD операции с растениями
- ✅ Offline-режим с кешированием
- ✅ Автоматическая синхронизация при восстановлении сети
- ✅ RLS политики безопасности

## Технологии

- Expo SDK 52
- React Native 0.76
- OnSpace Cloud (Supabase-compatible)
- TypeScript strict mode
- Offline-first архитектура

## Запуск

```bash
npm install
npm start
```
